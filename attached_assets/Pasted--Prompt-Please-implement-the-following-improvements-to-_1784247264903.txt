# 3. Create a "Maintenance Intervals" Configuration Page

Next to the **Export** button, add a new button called:

**Maintenance Intervals**

Clicking this button should open a new configuration screen where the user can define the preventive maintenance interval for each maintenance category.

## Example

| Category         | Maintenance Interval (KM) |
| ---------------- | ------------------------: |
| Engine Oil       |                 10,000 km |
| Fuel Filter      |                 20,000 km |
| Air Filter       |                 15,000 km |
| Brake Pads       |                 30,000 km |
| Tires            |                 60,000 km |
| Transmission Oil |                 80,000 km |
| Battery          |                 50,000 km |

The user must be able to:

* Add new interval rules.
* Edit existing intervals.
* Delete intervals.
* Save changes.

These intervals will be used to calculate preventive maintenance reminders.

# 4. Preventive Maintenance Dashboard

Create a new section on the **Dashboard** called:

**Preventive Maintenance**

This section should automatically analyze every fleet and determine when the next preventive maintenance is due based on:

* Last maintenance record.
* Odometer at the last maintenance.
* Current vehicle mileage.
* Configured maintenance interval.

# 5. Dynamic Status Indicators

Each maintenance item should display a color-coded status.

### Green

Maintenance is **not yet due**.

Example:

Next Oil Change:

10,000 km

Current KM:

5,800 km

Remaining:

4,200 km

Indicator:

🟢 Green

---

### Yellow

Maintenance is approaching.

Example:

Remaining distance is within approximately **20% of the configured interval**.

Example:

Interval:

10,000 km

Current Remaining:

1,800 km

Indicator:

🟡 Yellow

---

### Red

Maintenance is overdue or due immediately.

Example:

Remaining distance:

0 km or negative

Indicator:

🔴 Red

This maintenance should appear at the top of the Dashboard list.
