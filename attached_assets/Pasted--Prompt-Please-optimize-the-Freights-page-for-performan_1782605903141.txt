* Load only an initial batch of records (for example, 50 or 100 records).

* Continue loading additional batches until all records have been displayed.
* The loading should be seamless, with no page refresh or interruption.
* Keep scrolling smooth even when the database contains thousands of freight records.

The objective is to significantly improve the page's performance and reduce the initial loading time.

* If the user searches for a CTe number that has not yet been loaded into the visible list, it should still be found.

* Ensure memory usage remains low.
