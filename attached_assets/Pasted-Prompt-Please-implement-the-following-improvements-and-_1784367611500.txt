1. Automatically Update Vehicle Mileage in the Maintenance Module

The Maintenance page should always use the most up-to-date mileage available for each fleet.

Currently, the application already stores mileage information in multiple modules, such as:

* Diesel (Refueling records)
* Expenses
* Freights

These modules already contain enough information to determine the current mileage of each truck.

Mileage Calculation

The system should automatically determine the current mileage of each fleet by considering:

1. The latest recorded odometer from the Diesel module.
2. Any additional kilometers traveled since that refueling, calculated from subsequent Freight and Expense records (according to the application’s existing business rules).
3. The result should represent the most accurate current mileage for each truck.

The Maintenance module should always use this calculated mileage instead of relying on manually entered values whenever possible.

2. Preventive Maintenance Synchronization

* A new Expense affects mileage.

The preventive maintenance indicators must be recalculated automatically.

No manual refresh should ever be required.
