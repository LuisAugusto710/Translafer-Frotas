# Objective

The Dashboard has a **global time filter** (Month, Quarter, Semester, Year, Custom Range).

The **Revenue by Period** chart also has its own independent time scale selector.

I want the chart to automatically default to **one level below** the selected global period, providing a more meaningful breakdown of the selected data.

The user must still be able to manually change the chart's time scale at any time.

---

# Default Behavior

Apply the following automatic mapping:

| Global Dashboard Period | Default Chart Scale                                                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Year                    | Semester                                                                                                                                                |
| Semester                | Quarter                                                                                                                                                 |
| Quarter                 | Month                                                                                                                                                   |
| Month                   | Week                                                                                                                                                    |
| Custom Range            | Automatically choose the smallest logical subdivision based on the selected date range (prefer Week for ranges up to 3 months, Month for longer ranges) |

# Manual Override

The user must still be able to manually change the chart scale.

For example:

If the Dashboard is set to **Year**, the chart should initially open in **Semester**, but the user can change it to:

* Month
* Quarter
* Semester
* Year

The application must respect the user's selection until the global period filter changes again.
