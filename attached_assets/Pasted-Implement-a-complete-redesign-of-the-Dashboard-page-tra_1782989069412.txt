Implement a complete redesign of the **Dashboard** page, transforming it into a modern management dashboard for the transport company while keeping the existing visual identity of the application.

## General Requirements

* Keep the current design language, spacing, typography, colors, buttons, cards, and visual hierarchy consistent with the rest of the application.
* Do **not** modify any pages other than the Dashboard.
* Do **not** make unnecessary UI or structural changes outside of what is requested.
* The dashboard should feel like a natural extension of the current application.
* The interface must be clean, elegant, professional, and easy to understand.
* Prioritize readability and quick access to important information.
* Ensure the layout is fully responsive for desktop, tablet, and mobile devices.

---

# Dynamic Data

Every dashboard component must update automatically whenever data changes in any part of the system.

The Dashboard must always reflect the current data from:

* Freight table
* Expenses table
* Diesel table
* Any other related operational data

All calculations must be generated dynamically.

Do not use hardcoded values.

Any record added, edited, or deleted anywhere in the application must immediately update every dashboard metric, chart, ranking, and table.
