# 1. Include Diesel as an Expense in the Dashboard

Every diesel refueling recorded in the **Diesel** module must automatically be considered an **expense** for its respective fleet.

## Requirements

* Every diesel record must contribute to the total expenses of the corresponding fleet.
* The Dashboard must include diesel costs in:

  * Total Expenses
  * Profit Calculation
  * Fleet Cost Analysis
  * Charts
  * Reports
  * KPIs
* When filtering by fleet or date, only the corresponding diesel expenses should be included.
* There should be no need to manually create an expense record for diesel; it must happen automatically through the Diesel module.

---

# 2. Use the Last Fuel Price Instead of the Historical Average

Currently, when creating an expense, the **Diesel Price (R$/L)** is filled using the average of previous refuelings.

This behavior should be changed.

## New Logic

For each fleet:

* Use the **R$/L value from the most recent refueling** of that fleet.
* Do **not** use the historical average anymore.

Example:

Fleet 4104

Refueling History:

* 01/07 → R$ 5.89/L
* 05/07 → R$ 5.95/L
* 10/07 → R$ 6.02/L

Any expense created after **10/07** should automatically use:

**R$ 6.02/L**

If a new refueling is added:

15/07 → R$ 6.08/L

Then:

* Expenses created **before 15/07** must keep their original value.
* Only expenses created **after the new refueling** should automatically use **R$ 6.08/L**.

Historical data must never be recalculated or modified.
