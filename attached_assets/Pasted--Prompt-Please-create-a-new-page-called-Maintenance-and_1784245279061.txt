# Maintenance Page

The purpose of this page is to maintain a complete history of all maintenance performed on the company's fleet.

The layout should follow the same pattern used on the **Freights** and **Expenses** pages:

* Search bar at the top
* "Add Maintenance" button
* Responsive table
* Sticky table header
* Mobile-friendly layout
* Pagination/Lazy Loading consistent with the rest of the application

---

# Maintenance Form

Clicking **"Add Maintenance"** should open the maintenance form.

The following fields are **required**:

## General Information

### Maintenance Date

* Date the maintenance was performed.
* Required.

### Fleet Number

* Vehicle on which the maintenance was performed.
* Required.
* Use the existing Fleet list.

### Odometer (KM)

* Vehicle mileage at the time of maintenance.
* Numeric field.
* Required.

### Maintenance Type

Dropdown with:

* Preventive
* Corrective
* Emergency

Required.

### Procedure Performed

Free text field.

Examples:

* Oil Change
* Brake Pad Replacement
* Clutch Replacement
* Suspension Repair
* Tire Rotation
* Engine Overhaul

Required.

### Category

Dropdown with predefined categories:

* Engine
* Transmission
* Brakes
* Tires
* Electrical
* Suspension
* Cooling System
* Fuel System
* Lubrication
* Bodywork
* Air Conditioning
* Battery
* Filters
* General Maintenance
* Other

Required.

### Workshop / Supplier

Text field containing:

* Workshop name
* Supplier
* Service provider

Required.

### Total Cost

Currency field.

Required.

### Notes

Large multiline text area.

Optional.

Used for:

* Additional observations
* Replaced parts
* Warranty information
* Recommendations
* Next maintenance notes
