**Prompt:**

Please perform a **comprehensive responsive UI optimization** across the entire application while **preserving the existing design, layout, functionality, and visual identity**.

The objective is to make the application feel native on desktop, tablet, and mobile devices, ensuring that no text, numbers, buttons, tables, or cards break, overlap, or become difficult to read.

## 1. Fully Responsive Layout

Review every page in the application and optimize the layout for:

* Desktop (1920px+)
* Laptop
* Tablet
* Large phones
* Small phones (320px width and above)

The interface should adapt fluidly to every screen size.

## 2. Prevent Text and Number Overflow

One of the biggest issues is that text and numbers sometimes overflow or wrap incorrectly.

Please ensure that:

* Text never overflows its container.
* Numbers never overflow cards or table cells.
* Long values remain readable.
* Buttons never break onto multiple lines.
* Titles remain fully visible.
* Currency values are always displayed correctly.
* Dates remain readable on all screen sizes.

If necessary:

* Dynamically reduce font size.
* Increase available width.
* Allow intelligent wrapping only when appropriate.
* Keep important values on a single line whenever possible.

## 12. Modern Responsive Techniques

Where appropriate, use modern CSS techniques such as:

* CSS Grid
* Flexbox
* Responsive breakpoints
* Fluid typography (`clamp()`)
* Relative units (`rem`, `%`, `vw`, `vh`)
* Auto-fit and auto-fill layouts
* Dynamic container sizing

Avoid hardcoded widths and heights whenever possible.
